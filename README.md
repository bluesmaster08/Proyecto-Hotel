# Sistema de Reservación de Hotel

## Descripción
Aplicacion que describe el uso de la clase Thread y la interfaz Runnable para la ejecución concurrente de tareas. Este proyecto es un sistema de reservación de habitaciones de hotel desarrollado en **Java** utilizando NetBeans como entorno de desarrollo integrado. El sistema permite gestionar las reservas de habitaciones, mostrando un historial de reservaciones y proporcionando una interfaz gráfica de usuario (GUI) intuitiva.

## Estructura del Proyecto
El proyecto está organizado en las siguientes carpetas y archivos principales:

### Archivos de Configuración
- `build.xml`: Archivo de configuración para compilar y construir el proyecto.
- `manifest.mf`: Archivo que especifica metadatos del proyecto.
- `nbproject/`: Configuraciones específicas del proyecto en NetBeans.

### Código Fuente
La lógica del sistema se encuentra en la carpeta `src/`, organizada en los siguientes paquetes y clases:

#### **Paquete Clases**
- `ReservaHabitacion.java`: Clase principal que gestiona las reservas de habitaciones.

#### **Paquete proyectohotel**
- `FormularioMenu.java`: Clase que define el menú principal del sistema.
- `FormularioReservaciones.java`: Clase para la gestión y visualización de reservaciones.
- `FormularioHistorial.java`: Clase para mostrar el historial de reservaciones.
- `ProyectoHotel.java`: Clase principal que inicializa y ejecuta el sistema.

### Recursos Compilados
- `build/classes/`: Archivos compilados de las clases Java.

## Características del Proyecto
1. **Gestión de Reservas:** Permite registrar, consultar, y gestionar las reservaciones de habitaciones.
2. **Interfaz Gráfica:** Utiliza formularios diseñados con NetBeans para facilitar la interacción del usuario.
3. **Historial de Reservaciones:** Muestra un registro detallado de todas las reservas realizadas.

## Requisitos del Sistema
- **Java Development Kit (JDK):** Versión 8 o superior.
- **NetBeans IDE:** Versión compatible con JDK 8 o superior.

## Instrucciones de Configuración
1. Clona este repositorio en tu máquina local:
   ```bash
   git clone https://github.com/tuusuario/Hotel_Reservacion.git
   ```
2. Abre el proyecto en NetBeans.
3. Configura el JDK en NetBeans si aún no está configurado.
4. Ejecuta el archivo principal `ProyectoHotel.java` para iniciar el sistema.
